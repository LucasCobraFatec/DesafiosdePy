## 📌 Sobre o Projeto

O objetivo deste repositório é registrar minha evolução na linguagem Python, desde os conceitos mais básicos de lógica de programação até o uso de bibliotecas e estruturas de dados mais complexas.

### 🛠️ Tecnologias Utilizadas
* **Python 3**
* **PyCharm** (ou VS Code)
* **Git & GitHub**
